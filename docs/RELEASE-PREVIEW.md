# CSQTT Entware 0.1.0-preview.1

Экспериментальный клиент CSQTT 2.1.9 для Keenetic KN-1710, KeeneticOS 3.8.7 и
Entware MIPS32r2 little-endian soft-float с glibc 2.27.

Панель работает на LAN-адресе роутера, по умолчанию `192.168.2.1:8080`.
Она сохраняет параметры CSQTT и создаёт локальный WireGuard-профиль. Устройства
назначаются VPN-политике в штатном интерфейсе Keenetic. В политике CSQTT
оставляют только WireGuard, а DNS привязывают к этому подключению. Для обычных
устройств на KeeneticOS 3.8 нужна отдельная политика ISP без WireGuard.

После импорта вручную задайте MTU 1280 и сохраните подстройку TCP MSS.
При получении другого адреса CSQTT мост блокирует передачу до обновления профиля.
Используйте действующий серверный доступ для этого устройства: пароль другого
привязанного клиента не подходит.

Служба объединяет лёгкую статическую панель, управление и WireGuard-мост без
gVisor или отдельного TCP/IP-стека. Ядро сохраняет минимум девять транспортных
соединений и один поток Tokio; очереди и пулы пакетов ограничены.

Для подтверждения VK используется существующий Android Helper preview.10 из
исходного проекта. Его локальный HTTPS-брокер слушает LAN-порт 9443 и проверяется
по отпечатку сертификата. Управляемое ядро сразу предлагает CAPTCHA человеку,
сохраняя попытки задания для Helper.

Проверены тесты хоста, MIPS ABI/эмуляция, установка с сохранением данных,
реальные каналы CSQTT, штатный WG, DNS UDP/TCP и HTTPS через нативную политику.
Подробные подтверждения и текущие незавершённые проверки находятся в
[docs/STATUS.md](https://github.com/RATOR2000/csqtt-entware/blob/main/docs/STATUS.md).

Ограничения первого preview:

- IPv4; активация блокируется при обнаруженном IPv6-обходе.
- Проверено одно физическое устройство и синтетические параллельные потоки.
  Работа трёх физических устройств не подтверждена.
- Helper открыл реальную страницу VK; успешный возврат человеческого ответа
  ещё не подтверждён. До отдельного решения о границах preview этот выпуск
  остаётся черновиком.
- Скорость зависит от процессора роутера, сети и транспорта VK; гарантии скорости нет.

IPK содержит оба бинарных файла и полные тексты требуемых лицензий/NOTICE.
Установщик проверяет платформу и SHA256, сохраняет настройки, UUID и WG-ключи
при переустановке. Контрольные суммы защищены HTTPS; отдельной подписи выпуска нет.

Исходный репозиторий `csqtt-openwrt` не изменялся.
